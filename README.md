# Rossmann Store Sales Forecasting

## Project Objective
Develop a production-oriented machine learning solution to forecast daily sales for individual Rossmann stores over a six-week horizon.

The solution will evaluate global forecasting models across stores, compare alternative modelling approaches, and translate forecast performance into business impact.

## Project Structure
- data/raw: Original competition datasets
- data/processed: Cleaned and engineered datasets
- notebooks: Exploratory analysis and experiments
- src: Modular Python implementation
- models: Trained model artefacts
- reports: Evaluation and executive reports
- architecture: Production architecture documentation

## Technology Stack
Python, Pandas, NumPy, Scikit-learn, LightGBM, Statsmodels, Matplotlib, Seaborn and Jupyter.

## Modelling Approach
A global model across stores will be evaluated as the primary approach. Alternative and hybrid approaches will be considered based on validation results.
